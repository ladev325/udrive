# UDrive

Приватное пространство для файлов, фотографий, заметок, чатов и сейфа.
Фронтенд на React 19 + Vite, без обязательного бэкенда: данные хранятся в браузере.

## Что внутри

- **Вход по email с паролем из письма** — при регистрации генерируется пароль, показывается демо-письмо, после чего можно сразу войти. Для существующего аккаунта доступно восстановление пароля.
- **Google-вход** — настоящий Google Identity Services при наличии `VITE_GOOGLE_CLIENT_ID`; без настройки открывается явно помеченный демо-выбор аккаунта.
- **Приватный сейф** — необязательный пароль, PBKDF2 (210 000 итераций) + AES-256-GCM. Пароль не хранится в открытом виде и не восстанавливается. Записи шифруются и переживают перезагрузку.
- **Заметки** — отдельный редактор с заголовком, тегами, цветами, закреплением, markdown-панелью, автосохранением и предпросмотром.
- **Чаты** — отдельный раздел с диалогами, непрочитанными и локальной историей.
- **Адаптивность** — боковое меню превращается в drawer по кнопке, добавлена нижняя навигация на телефоне, панели заметок и чатов переключаются между списком и диалогом.
- **Навигация** — быстрые действия, счётчики, поиск по разделу, `Ctrl/⌘ + K`, контекст раздела в шапке, профильное меню.
- **Синхронизация с телефоном** — настоящий QR-код и экран сопряжения. В рамках фронтенда связь работает через `BroadcastChannel` между вкладками/окнами одного браузера (см. ограничения).
- **RU / UA / EN** — полный перевод интерфейса, локализованные даты и форматтеры.
- **Полировка** — счётчики, автоудаление временных файлов, подтверждения удаления, тосты, доступные подписи, шифрование сейфа, резервные копии заметок и чатов.

## Google OAuth

Создайте OAuth Client ID типа **Web application** в Google Cloud Console и добавьте
authorized JavaScript origins: `http://localhost:5173` и домен продакшена.

Создайте `.env.local`:

```env
VITE_GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
```

После перезапуска `npm run dev` кнопка Google будет использовать настоящий OAuth.
Без переменной приложение откроет демо-выбор аккаунта — это сделано намеренно,
чтобы интерфейс можно было проверить без настройки Google Cloud.

## Важно: что является демо, а что настоящим

Это **фронтенд-проект**, поэтому часть функций работает локально:

| Функция | Статус |
| ------- | ------ |
| Генерация пароля и вход по нему | Реально, аккаунт хранится в `localStorage` |
| Письмо с паролем | Демо-инбокс: почтового сервера нет. Для реальной отправки нужен SMTP/API на бэкенде |
| Google OAuth | Реально при `VITE_GOOGLE_CLIENT_ID`, иначе демо-выбор |
| Сейф | Реально: Web Crypto, PBKDF2 + AES-GCM |
| Заметки, чаты, файлы, фото | Реально, в рамках текущего браузера |
| Синхронизация с телефоном | Демо между вкладками одного браузера. Для другого устройства нужен серверный signaling/relay |

Для продакшена также нужен настоящий auth-сервис: клиентская проверка пароля
подходит для прототипа, но не заменяет серверную авторизацию.

## Данные

- аккаунты — `localStorage` (`nexus_accounts_v2`), пароль хранится только как PBKDF2-хэш;
- заметки и чаты — `localStorage`, ключи отдельные для каждого `user.id`;
- файлы и фото — `IndexedDB` (`NexusDB`), также отдельно для каждого пользователя;
- сейф — зашифрованные метаданные и записи в `localStorage`;
- сессия — `localStorage`; при выходе очищается, вкладки сбрасываются на «Файлы».

Временные файлы и фото удаляются через 7 дней, если не нажать звёздочку
«Сохранить». Удаление просроченных записей проверяется при загрузке и раз в минуту.

## Структура

```text
src/
  App.jsx                 — маршрутизация состояния, данные пользователя, layout
  components/
    AuthScreen.jsx        — вход, регистрация, демо-письмо, Google
    Sidebar.jsx           — навигация и drawer
    Header.jsx            — поиск, профиль, контекст раздела
    PairDevicePage.jsx    — экран телефона после QR
    Tabs/                 — файлы, фото, сохранённое, заметки, чаты, сейф, синк, настройки
    Modals/               — загрузка, настройка сейфа, новый чат
  utils/
    auth.js               — аккаунты, PBKDF2, сессия, Google-профиль
    vault.js              — PBKDF2 + AES-GCM для сейфа
    db.js                 — IndexedDB
    sync.js               — QR, код сопряжения, BroadcastChannel
    formatters.js         — размеры, даты, буфер обмена
  data/translations.js    — RU / UA / EN
```

## Известные ограничения

- реальная отправка писем не подключена;
- межбраузерная/межсетевая синхронизация требует сервера;
- сброс пароля сейфа удаляет зашифрованные записи — это осознанное ограничение;
- аккаунты и данные не покидают браузер, поэтому очистка site data удалит всё.
